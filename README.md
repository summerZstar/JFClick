## 功能特性

### 1. 快速点击（连点器）

节奏模式二选一（互斥）：
- **频率模式**：设定「次/秒」，按稳定频率精准点击，无漂移。
- **间隔模式**：设定「每次点击后等待 min~max 秒」，支持随机抖动，模拟人工节奏；0~0 即最快连点。

点击位置：支持「固定坐标」和「跟随光标」两种模式。

停止条件：点击次数 / 运行时长 / 无限循环，三种任选。

实时状态：运行中实时显示「已点击次数」与「运行时间」。

### 2. 录制回放（动作宏）

录制：一键录制鼠标移动、点击、键盘输入全过程，动作列表实时刷新。

动作列表：以「时间 / 动作 / 详情」三列表格清晰展示，支持删除选中、一键清空。

回放设置：
- 停止条件：运行次数 / 运行时长 / 无限循环。
- 速度倍率调节（加速或减速回放）。
- 一轮后间隔：完整播放一个录制周期后再停顿 min~max 秒（随机），0~0 表示不休息。

实时统计：回放时实时显示「运行次数」和「运行时间」。

### 3. 配置管理

- 保存 / 加载配置：快速点击配置、录制动作均可存为文件，随时复用。
- 智能目录记忆：默认保存在程序同级的 config 文件夹，首次自动创建；修改过目录后下次自动记住。
- 快捷键冲突拦截：若不同功能设了相同快捷键，保存时自动提示，避免冲突。

### 4. 亮点细节

- **屏幕绿框提示**：开始点击或回放时，屏幕四周边框亮起绿色提示框，随时掌控运行状态。
- **全局快捷键**：拾取坐标、开始点击、开始录制、播放、紧急停止，全部可自定义；紧急停止默认 ESC 键，一键收手。
- **按钮智能门控**：进入录制页默认只有「开始录制」可用，有数据后才解锁「播放」，防误操作。
- **高精度无漂移调度**：采用高精度计时器调度点击，频率模式下次数与时长严格准确（例：5 次/秒 × 3 秒 = 正好 15 次）。
- **坐标精准一致**：录制与回放使用同一坐标系，杜绝坐标自动偏移、位置错位问题。

## 快速上手

- **连点场景**：切到「快速点击」页 → 选频率或间隔 → 设位置与停止条件 → 按「开始点击」即可，想停按 ESC。
- **自动操作场景**：切到「录制回放」页 → 点「开始录制」做一遍操作 → 点「停止录制」→ 设回放次数/时长 → 点「播放」，循环自动执行。
